# Football Player Rating Prediction

## Overview

This project predicts football player ratings using machine learning based on player statistics, match information, and performance metrics.

The model was developed for a Kaggle competition and uses XGBoost regression to predict continuous player ratings.

---

## Dataset

The dataset includes:

- Player information
- Match statistics
- Team information
- Offensive and defensive metrics
- Advanced football statistics (xG, xA, etc.)


## Data Preprocessing

The preprocessing pipeline includes:

- Removing identifier columns
- One-hot encoding categorical features
- Aligning training and test feature columns
- Splitting the training data into training and validation sets

- Scikit-learn
- XGBoost
